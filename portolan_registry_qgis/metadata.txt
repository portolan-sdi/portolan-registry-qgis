about=Lists every catalog in the Portolan registry and walks each catalog's STAC tree. Adds PMTiles as vector tile layers styled with the catalog's own MapLibre style, read through QGIS's network settings. Loads GeoParquet through DuckDB, limited to the map extent when you choose. Opens GeoJSON, FlatGeobuf, COG, and COPC assets over HTTP without a download. Downloads an asset, a collection, or a whole catalog into a folder that keeps the catalog's layout, and verifies each file against its file:checksum. GeoParquet needs DuckDB 1.5.0 or newer in QGIS's Python; the plugin shows the install command when it is missing.
